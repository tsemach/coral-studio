## What this is

Marketing site for **Glumački Studio**, a non-profit acting studio in Belgrade run by Coral Mizrachi. Single-page marketing site (`app/page.tsx`) built from section components, plus a `/login` page. Content/copy source of truth lives in `docs/GLUMAČKI-STUDIO—WEBSITE-CONTENT.md` — check it before writing or editing on-page copy so components stay aligned with the approved text.

## Commands

```

pnpm build    # production build
pnpm start    # run production build
pnpm lint     # eslint .
```

No test suite is configured. Package manager is pnpm (`pnpm-lock.yaml` is present — don't introduce npm/yarn lockfiles).

## Before writing code

Per `AGENTS.md`, this repo pins a Next.js version with breaking changes vs. training data. Read the relevant guide under `node_modules/next/dist/docs/` before writing App Router code, and don't remove the `AGENTS.md` banner — it's regenerated by `next dev` on every run.

## Architecture

- **App Router**, one route per marketing surface: `app/page.tsx` (home) composes section components in order from `components/`; `app/login/page.tsx` is a static form page (no auth wired up yet — it's UI only).
- **Section components** (`components/*.tsx`) are the unit of composition: each is a self-contained `<section>` for one part of the homepage (`hero`, `about-section`, `disciplines-section`, `approach-section`, `classes-section`, `workshop-section`, `teacher-section`, `community-section`, `faq-section`, `final-cta`), imported and stacked in `app/page.tsx`. `site-header.tsx` is the only client component (`'use client'`, for mobile menu state); everything else is a server component. New homepage sections follow this same pattern: a named export function returning one `<section>`, added to `components/` and wired into `app/page.tsx`, and anchored via `id` for the header's hash links (`/#about`, `/#workshop`, `/#community`, `/#contact`).
- **Styling**: Tailwind v4 via `@import 'tailwindcss'` in `app/globals.css`, with the design system defined as CSS custom properties in an inline `@theme` block (not `tailwind.config.*` — there isn't one). Color tokens: `background`/`foreground`/`muted`/`card`/`border` for the light page surface, `primary`/`accent` for CTAs/highlights, `ink`/`ink-foreground` for the dark hero/login surfaces. Reuse these tokens (`bg-primary`, `text-ink-foreground/70`, etc.) rather than introducing raw colors. Fonts: Geist Sans (`--font-sans`) and Fraunces (`--font-serif`, used for headings), both loaded via `next/font/google` in `app/layout.tsx`.
- **Security headers** are set centrally in `next.config.mjs` (`X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`) — extend that `headers()` function rather than adding per-route headers.
- Path alias `@/*` maps to the repo root (see `tsconfig.json`).
