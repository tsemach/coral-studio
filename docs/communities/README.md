# Glumački Studio — Communities Architecture & Roadmap

## Vision
The Communities section is a dedicated, authenticated space for actors at Glumački Studio to collaborate, build relationships, support each other's craft, and exchange opportunities. Rather than a generic social feed, the platform is structured around high-utility workflows addressing the everyday realities of working and training actors.

## Sub-Projects

1. **[Sub-project 1: The Actor Board](./subproject-1-actor-board/README.md)**
   * **Scope:** Foundational community hub and feed.
   * **Core Value:** Categorized discussion, urgent scene partner requests (`#reader-sos`), local auditions & recommendations (`#the-callboard`), and technique discussions (`#craft-chat`).

2. **[Sub-project 2: The Tape Room](./subproject-2-tape-room/README.md)**
   * **Scope:** Video self-tape review & peer critique.
   * **Core Value:** Secure monologue and audition clip uploads with timestamped comments and craft-focused feedback tags.

3. **[Sub-project 3: Instant Virtual Rehearsal](./subproject-3-instant-rehearsal/README.md)**
   * **Scope:** Real-time 1-on-1 virtual line reading powered by LiveKit.
   * **Core Value:** Instant virtual rehearsal rooms connected to Reader SOS posts, allowing paired actors to run scenes remotely with side-by-side script viewing.
