# Sub-project 3: Instant Virtual Rehearsal Room

## 1. Overview
Instant Virtual Rehearsal integrates the studio's existing LiveKit real-time audio/video infrastructure with the community feed, enabling two actors to jump directly into a private, low-latency rehearsal space from a `#reader-sos` post.

## 2. Main Idea & Core Pillars

1. **One-Click Rehearsal Rooms**
   * When an actor accepts a `#reader-sos` request, either actor can click "Open Rehearsal Room".
   * A private, ephemeral LiveKit video room is spun up immediately without needing third-party links (Zoom, Google Meet).

2. **Side-by-Side Scene Viewer (Tele-Reader)**
   * During the video call, actors can view the attached sides or script side-by-side with the video stream.
   * Highlight lines, scroll in sync, or reference character notes while rehearsing.

3. **Rehearsal History & Favors Exchanged**
   * Tracks reading sessions completed to acknowledge actors who regularly support their peers as readers.
