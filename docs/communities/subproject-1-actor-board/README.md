# Sub-project 1: The Actor Board (Core Community Feed)

## 1. Overview
The Actor Board is the foundational community space for authenticated Glumački Studio members. It replaces empty general talk with targeted, high-utility channels that address everyday actor needs.

## 2. Main Idea & Core Pillars
Actors need timely peer support, casting visibility, and a safe space to discuss craft. The Actor Board organizes discussions into three structured categories:

1. **`#reader-sos` (Scene Partner & Line-Reading Exchange)**
   * **Purpose:** Allows an actor to post urgent requests for line readers for self-tapes, auditions, or workshop rehearsals.
   * **Metadata:** Rehearsal timing (e.g., "Tonight at 20:00"), scene length/nature (e.g., "2 pages, dramatic"), and meeting preference (in-studio or virtual).
   * **Status Chips:** `Seeking Reader`, `Filled / In Progress`, `Completed`.

2. **`#the-callboard` (Auditions, Castings & Local Intel)**
   * **Purpose:** Centralized hub for Belgrade/regional casting calls, student productions (FDU, BK, etc.), indie projects, and vetted professional recommendations (photographers, coaches, showreel editors).
   * **Metadata:** Project type tags (`Short Film`, `Theatre`, `Feature`, `Commercial`), casting deadlines, and contact information.

3. **`#craft-chat` (Technique, Scene Study & Studio Q&A)**
   * **Purpose:** Focused discussions on acting methods, character choices, workshop reflections, and scene analysis questions.
   * **Format:** Threaded Q&A with rich text, markdown formatting, and image attachments.

## 3. Key Capabilities
* **Authenticated Access:** Only active, approved studio members can view and post.
* **Threaded Discussions:** Top-level posts with dedicated reply threads to keep discussions organized.
* **Media Attachments:** Upload photos, sides/scripts, or reference images via Vercel Blob.
* **Member Profiles & Badges:** Displays member role, studio workshop participation badges, and community contribution karma.
* **Search & Tag Filtering:** Quickly filter by channel, date, or status.
